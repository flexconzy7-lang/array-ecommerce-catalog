What is an Array & Why is it Important?

Definition: An array is a data structure used to store multiple values in a single variable, organized sequentially under numbered indexes.

Importance in this App: Without arrays, managing dozens of product records, filtering categories dynamically, and calculating shopping cart totals would require unmanageable individual variables. Arrays allow us to use powerful methods like .map(), .filter(), and .reduce() to process data cleanly and efficiently.
